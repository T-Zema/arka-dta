# The Lost Temple (StarCraft) for DTA — archive (2026-10-24)

StarCraft's **(4)Lost Temple** converted to a Dawn of the Tiberium Age skirmish map (2–4 players), generated by
`Modding/tools/convert-scmap.ps1` from the user's StarCraft: Remastered install. Full write-up:
`Modding/wiki/mods/sc-lost-temple.md`.

## Contents

| Path | What |
|---|---|
| `modified/Maps/Custom/sc_lost_temple.map` | the map (new file, nothing in the game is changed) |
| `modified/Maps/Custom/sc_lost_temple.png` | client preview, 800×819 |
| `tools/` | snapshot of the converter used to build it (`port-scmap.ps1` pipeline, `convert-scmap.ps1`, `ScToDta.cs`, `TsMap.cs`, `ScMap.cs`; also needs `Casc.cs` and `ModTools.cs` from `Modding/tools`) |
| `review.png`, `summary.json` | pipeline review sheet (original / DTA / reachability) and check numbers |

The map was regenerated the same day with the improved converter (thin skeleton walls, narrow-channel fixes).

There is no `original/` folder because the mod only adds new files.

## Install

Copy `modified/` over the game root. In the client: Skirmish → game mode **Custom Map** → "The Lost Temple (StarCraft)".

## Uninstall

Delete `Maps/Custom/sc_lost_temple.map` and `Maps/Custom/sc_lost_temple.png`.

## Status

Checked with the CNCMaps renderer and a ground-connectivity test (all 4 starts connected; the island bases and the
plateaus without ramps are unreachable by ground, as in StarCraft). Not yet tested in the game.
